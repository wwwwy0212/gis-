# 面重叠处理工具 v1.3

ArcGIS 10.6 Python Toolbox (.pyt)，单图层内部面重叠一键去除。

## 功能

- 输入：单个面要素图层
- 自动检测图层内部所有局部重叠
- 重叠区域默认保留 OBJECTID 较小的图斑属性
- **优先保留选项（v1.3 新增）**：可选择输入图层的任意字段作为优先级判断依据。两个图斑重叠时，比较该字段的值，保留值较小的一方。不选择该选项时，沿用默认逻辑（按 OBJECTID 保留）。适用于需要按自定义规则决定保留顺序的场景（如按面积、编号、等级等字段）
- 重叠部分与非重叠部分按原始图斑归并，输出图斑数 = 输入图斑数
- 输出：无任何空间重叠的干净面图层，完整保留原始属性

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 输入面图层 | Feature Layer | 是 | 要进行内部去重叠的面图层 |
| 输出成果图层 | Feature Class | 是 | 处理结果的输出路径 |
| 优先保留字段 | String | 否 | 指定字段后按该字段值小者优先保留；不选则默认按 OBJECTID |

## 算法流程

```
自相交提取 → 删除相同项（按优先级/OID 保留） → 擦除重叠区 → 按原始图斑合并碎片输出
```

## 分发

只需一个文件：`面重叠处理工具.pyt`

## 使用方法

1. 打开 ArcMap 10.6 → ArcToolbox
2. 右键 → 添加工具箱
3. 选择 `面重叠处理工具.pyt`
4. 双击「面重叠处理工具」→ 选择输入图层 → 设置输出路径 →（可选）选择优先保留字段 → 确定
