# 面重叠处理工具

ArcGIS 10.6 Python Toolbox (.pyt)，单图层内部面重叠一键去除。

## 功能

- 输入：单个面要素图层
- 自动检测图层内部所有局部重叠
- 重叠区域保留 OBJECTID/FID 较小的图斑属性
- 输出：无任何空间重叠的干净面图层

## 使用方法

1. 打开 ArcMap 10.6 → ArcToolbox
2. 右键 → 添加工具箱
3. 选择 
4. 双击「面重叠处理工具」→ 输入图层 → 输出路径 → 确定
